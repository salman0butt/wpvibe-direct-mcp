# Debugging

Reproduce first and gather evidence across layers. Use site_info, route discovery, rendered HTML, file/content search, audit logs, and safe WP-CLI reads. Form one hypothesis, make the smallest reversible change, and verify the original symptom. Do not weaken security settings to hide an error.

## Workflow

Inspect current state first, make the smallest supported change, verify the result, and preserve WordPress/WPVibe capability and approval checks.
