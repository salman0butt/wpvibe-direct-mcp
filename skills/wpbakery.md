# Wpbakery

WPBakery commonly stores nested shortcodes in post_content. Read the target first and preserve shortcode nesting/attributes. Use search_content/edit_content for precise changes instead of replacing unrelated rows; verify rendered HTML and clear only relevant caches.

## Workflow

Inspect current state first, make the smallest supported change, verify the result, and preserve WordPress/WPVibe capability and approval checks.
