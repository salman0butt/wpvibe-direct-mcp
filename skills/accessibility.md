# Accessibility

Preserve semantic landmarks, heading order, form labels, keyboard operation, visible focus, alt text, contrast, reduced-motion preferences, and responsive zoom. Treat accessibility as a verification step after visual changes, not as decorative metadata. Avoid ARIA when native HTML already provides the correct semantics.

## Workflow

Inspect current state first, make the smallest supported change, verify the result, and preserve WordPress/WPVibe capability and approval checks.
