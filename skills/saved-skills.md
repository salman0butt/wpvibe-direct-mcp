# Saved Local Skills

Use saved skills for site- or organization-specific operating procedures that should persist on this WordPress installation. `create_skill`, `update_skill`, and `delete_skill` require one-time browser approval; built-in plugin skills are immutable. Direct re-reads saved-skill storage after each mutation and fails closed if the intended create/update/delete did not persist, so a successful response is evidence of durable state rather than an in-request-only change. Keep instructions concise, operational, and free of passwords, API keys, customer secrets, or binary data. Use a stable lowercase slug and update an existing local skill rather than creating near-duplicates. `list_skills` and `load_skill` merge built-in and local entries.
