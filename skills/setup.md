# Setup

Start with site_info and discover_rest_routes. Confirm WPVibe version, WordPress version, token-owner capabilities, available builders, and file-edit locks before changing anything. Prefer feature detection over assumptions. Keep writes in draft or sandboxed flows until the user explicitly asks to publish.

## Workflow

Inspect current state first, make the smallest supported change, verify the result, and preserve WordPress/WPVibe capability and approval checks.
