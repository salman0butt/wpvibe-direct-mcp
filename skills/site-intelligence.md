# Site Intelligence

Start broad WordPress work with `site_intelligence`, `site_info`, and `integration_capabilities`. These report WordPress/PHP/WPVibe versions, route availability, Abilities support, live-reload support, and detected builders without exposing filesystem paths or secrets. Feature detection is authoritative: only use native builder routes when present, and fall back to public REST/Abilities or draft-theme editing otherwise. Re-check capabilities after plugin/theme upgrades because integrations can appear or disappear independently of Direct MCP.
