# GeneratePress / GP Premium

Detect GeneratePress or GP Premium before using theme-specific assumptions. Prefer public WordPress options, registered post meta, REST routes, Abilities, and GP Elements exposed by the installed site; do not reverse-engineer serialized private state. Preserve hooks, display rules, typography, colors, container widths, and navigation behavior. Use draft-theme tools for PHP/CSS template changes, validate any GenerateBlocks content independently, preview the result, and require explicit approval before publishing.
