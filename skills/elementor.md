# Elementor

Use Elementor native WPVibe routes for widget discovery, schemas, style schemas, page saves, and templates. Do not write _elementor_data directly. Preserve document type, page template, responsive settings, post status, conditions, and stable element IDs; verify frontend output after save.

## Workflow

Inspect current state first, make the smallest supported change, verify the result, and preserve WordPress/WPVibe capability and approval checks.
